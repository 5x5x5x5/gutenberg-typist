*gt.txt*  Touch typing practice on Project Gutenberg books

                                                *gt* *gutenberg-typist*

Type real books, inside Vim. Learned to type with GNU gtypist? This is the
graduation: no more drills — keep your fingers sharp on the classics, then
compare notes at the typist guild leaderboard.

    https://5x5x5x5.github.io/typist-guild/

1. REQUIREMENTS                                              *gt-requirements*

- Vim 8.2 or newer (popups, text properties, jobs)
- `curl` on $PATH (book search and download)

==============================================================================
2. COMMANDS                                              *gt-commands* *:GT*

:GT search {query}                                                *:GT-search*
    Search Project Gutenberg (via gutendex) and pick a book from the
    results. Selecting a book downloads it (cached locally afterwards)
    and opens the typing view: source text on the left with
    per-character feedback, your typing buffer on the right.

:GT start {book_id}                                                *:GT-start*
    Start typing a book directly by its Gutenberg id.

:GT resume                                                        *:GT-resume*
    Pick up where you left off. With one in-progress book it resumes
    immediately; with several it opens a picker showing each book's
    progress and when you last touched it.

:GT stop                                                            *:GT-stop*
    End the session. Progress is saved (also happens automatically when
    you leave the typing buffer) and a one-line recap is shown: session
    WPM, accuracy, chars, duration.

:GT stats                                                          *:GT-stats*
    Popup with current-session and lifetime stats. Close with q or
    <Esc>.

:GT library                                                      *:GT-library*
    Pick from books already downloaded (works offline).

:GT export [{file}]                                               *:GT-export*
    Write a portable stats bundle (default ~/gutenberg-typist-export.json):
    your closed session records plus per-book resume progress. The format
    is SPEC.md in the typist-guild repo (schema 1).

:GT import {file}                                                 *:GT-import*
    Merge a bundle exported on another machine. Records are immutable
    and merge by set union on their ids, so re-importing (or importing
    an old bundle) never double-counts — it simply adds nothing. Old
    counter-format (v0) bundles are refused: update the plugin on the
    exporting machine and re-export there instead.

:GT publish                                                      *:GT-publish*
    Put your stats on the typist guild board: exports a bundle and
    uploads it (async, needs curl). Publishing is idempotent like
    |:GT-import| — the guild unions session records by id, so
    republishing never double-counts. Requires |g:gt_hub_token|. The
    response is kept in g:gt_hub_last for inspection.

==============================================================================
3. CONFIGURATION                                                   *gt-config*

All options are optional. Defaults: >

    call gt#Setup({
          \ 'split_ratio': 0.5,
          \ 'save_interval_ms': 5000,
          \ 'wpm_window_seconds': 10,
          \})
<
                                                             *g:gt_machine_id*
Stats are recorded per machine, keyed by hostname. Set this to override —
machine ids are shown on your guild board profile: >

    let g:gt_machine_id = 'laptop'
<
                                                *g:gt_hub_token* *g:gt_hub_url*
|:GT-publish| needs a token: sign in with GitHub on the guild board's
/account page, generate one, and set it (the account page prints these
exact lines): >

    let g:gt_hub_token = 'gt_...'
<
g:gt_hub_url overrides the guild instance for self-hosted boards.

==============================================================================
4. HIGHLIGHTS                                                  *gt-highlights*

Override these groups to match your colorscheme:

    GTCorrect     typed correctly (default: green)
    GTWrong       typo (default: red)
    GTUntyped     not yet reached (default: gray)
    GTCursor      next character to type (default: inverse)

==============================================================================
5. DATA & SYNC                                                       *gt-sync*

Everything lives under ~/.vim/gutenberg-typist/ : >

    books/{id}/text.txt, metadata.json    cached books
    sessions/{id}.json                    per-book progress
    session_log.json                      one record per typing session
<
Each finished session appends one immutable record (machine, date, book,
chars, errors, corrections, active time). Nothing leaves the machine
except what you see in an export: no keystroke timings, no clock times —
dates only. Stats from before the session log are folded in once as a
single "legacy" record per machine.
Cross-machine sync is |:GT-export| on one machine, copy the file, and
|:GT-import| on the other. The public leaderboard is one command —
|:GT-publish| — or upload an export on the guild's /account page:

    https://5x5x5x5.github.io/typist-guild/

==============================================================================
6. SPECIAL CHARACTERS                                            *gt-digraphs*

Books keep their original typography: em dashes, curly quotes, accented
words. Type them with Vim's built-in |digraphs|: in insert mode press
CTRL-K and two characters. The most common in Gutenberg texts:

    —  CTRL-K -M        '  CTRL-K '9        é  CTRL-K e'
    –  CTRL-K -N        "  CTRL-K "6        è  CTRL-K e!
    …  CTRL-K ,.        "  CTRL-K "9        æ  CTRL-K ae

Accent pattern: letter + ' (acute), ! (grave), > (circumflex),
: (umlaut), ? (tilde), , (cedilla). List everything with |:digraphs|.
Full guide: https://5x5x5x5.github.io/gutenberg-typist/digraphs.html
